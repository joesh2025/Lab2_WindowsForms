LAB 2 - WINDOWS FORMS APPLICATION

Open Lab1.sln in Visual Studio.

Run the Lab1Forms project (set it as the Startup Project if needed).

How to use:
1. Enter any non-empty username and password, then click Login.
2. Choose Bicycle or Mushroom.
3. Bicycle: enter a starting hour (0-23) and ending hour (1-24), then click Calculate.
4. Mushroom: answer the Yes/No questions to identify the mushroom.
5. Back returns to the Choose screen.
6. Logout returns to the Login screen.

The lab instructions require only that the username and password are not empty.
There is no fixed username/password authentication.
